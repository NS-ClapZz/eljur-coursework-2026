# Условие задания

Письмо: «ИСРПО 12–13. Практическая работа №3», 08.10.2026, Владимир Владимирович Горланов. Полное условие доступно по ссылке Gamma из письма.

Требуется API магазина одежды: сущности одежды, размеров/остатков, заказов и пользователей; публичный каталог и поиск по части названия; регистрация и авторизация; авторизованные заказы и просмотр; менеджерские операции по статусам заказов, количеству размеров и доступности товара. Пароли хранятся как хеш.
