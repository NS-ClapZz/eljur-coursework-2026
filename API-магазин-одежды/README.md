# ИСРПО 12–13: API магазина одежды

Я подготовил ASP.NET Core API с SQLite. В проекте я реализовал каталог и поиск по части названия, регистрацию и вход, хеширование паролей, роль менеджера, учёт наличия размеров, оформление заказов с проверкой и списанием остатков, историю заказов с фильтром по статусу и управление остатками, доступностью товара и статусами. Для каждого заказа я сохраняю название, размер и цену на момент покупки.

Для менеджера я предусмотрел настройку `CLOTHES_MANAGER_PASSWORD`; логин задаётся через `CLOTHES_MANAGER_LOGIN` (по умолчанию `manager`). При первом запуске каталог и база создаются автоматически. Я собрал проект и проверил основные сценарии API: каталог и поиск, регистрацию и вход, ответы 401 и 403, создание заказа, историю заказов и менеджерские операции. В Postman Lightweight API Client я отправил `GET /api/health` и `GET /api/clothing` — оба вернули `200 OK`. Снимки находятся в `docs/screenshots/`. Полный набор запросов из коллекции Postman в приложении пока не прогнан.

Я добавил коллекцию `ClothesApi.postman_collection.json` и окружение `ClothesApi.postman_environment.json` с локальным адресом `http://localhost:5000`, чтобы повторить запросы. Для менеджера используй собственный пароль через переменную `CLOTHES_MANAGER_PASSWORD`; пароль для демонстрации в архив не включён.

В исходном условии есть командные пункты: совместная работа в GitHub, распределение задач, ветки, постепенные коммиты и демонстрация запросов в Postman. Я выполняю проект самостоятельно, поэтому подготовил самостоятельную версию и не заявляю вклад команды или преподавателя.
