# ИСРПО 12–13: API магазина одежды

Реализован ASP.NET Core API с SQLite: каталог и поиск по части названия, регистрация и вход, хеширование паролей, менеджерская роль, наличие размеров, оформление заказов с проверкой и списанием остатков, история с фильтром по статусу и управлением остатками/доступностью/статусами. В заказе сохраняются название, размер и цена на момент покупки.

Для менеджера задайте `CLOTHES_MANAGER_PASSWORD`; логин задаётся через `CLOTHES_MANAGER_LOGIN` (по умолчанию `manager`). Каталог и база создаются автоматически при первом запуске. Сборка проекта проверена; локально проверены ответы HTTP для каталога/поиска, регистрации и входа, запрета доступа без авторизации (401), создания заказа и просмотра истории, а также менеджерских операций и запрета доступа обычному пользователю (403). Для повторения запросов добавлена коллекция Postman; запросы запускались локально через HTTP-клиент, не в интерфейсе Postman.

Командные пункты исходного условия — совместная работа в репозитории GitHub, распределение задач, ветки, постепенные коммиты и демонстрация запросов в Postman — требуют участия команды и преподавателя, поэтому в этом архиве представлен самостоятельный локальный проект.
