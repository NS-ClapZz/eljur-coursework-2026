# ИСРПО 12–13: API магазина одежды

Я подготовил ASP.NET Core API с SQLite. В проекте я реализовал каталог и поиск по части названия, регистрацию и вход, хеширование паролей, роль менеджера, учёт наличия размеров, оформление заказов с проверкой и списанием остатков, историю заказов с фильтром по статусу и управление остатками, доступностью товара и статусами. Для каждого заказа я сохраняю название, размер и цену на момент покупки.

Для менеджера я предусмотрел настройку `CLOTHES_MANAGER_PASSWORD`; логин задаётся через `CLOTHES_MANAGER_LOGIN` (по умолчанию `manager`). При первом запуске каталог и база создаются автоматически. Я собрал проект и локально проверил HTTP-ответы для каталога и поиска, регистрации и входа, запрета доступа без авторизации (401), создания заказа и просмотра истории, менеджерских операций и запрета доступа обычному пользователю (403). Я добавил коллекцию Postman, чтобы повторять запросы; сами запросы запускал локально через HTTP-клиент, а не в интерфейсе Postman.

В исходном условии есть командные пункты: совместная работа в GitHub, распределение задач, ветки, постепенные коммиты и демонстрация запросов в Postman. Я выполняю проект самостоятельно, поэтому подготовил самостоятельную локальную версию и не заявляю вклад команды или преподавателя.
