# ИСРПО 12–13: API магазина одежды

Я подготовил ASP.NET Core API с SQLite. Я реализовал каталог и поиск без учёта регистра, регистрацию и вход, хеширование паролей, роль менеджера, учёт наличия размеров, создание заказов с проверкой и списанием остатков, историю заказов с фильтром по статусу, управление остатками, доступностью товара и статусами заказов. Для каждого заказа я сохраняю название, размер и цену на момент покупки.

Я предусмотрел настройку менеджера через `CLOTHES_MANAGER_PASSWORD`; логин задаётся через `CLOTHES_MANAGER_LOGIN` и по умолчанию равен `manager`. Я настроил автоматическое создание каталога и базы при первом запуске. Я собрал проект: 0 ошибок и 0 предупреждений. Затем я прогнал коллекцию из 13 запросов в Newman на отдельной временной SQLite-базе: все 22 автоматические проверки прошли. Я проверил поиск по строчным буквам, регистрацию и вход покупателя, заказ, вход менеджера, смену статуса, остатка и доступности товара.

Я добавил коллекцию `ClothesApi.postman_collection.json` и окружение `ClothesApi.postman_environment.json`. Для локального прогона я указываю адрес API и задаю `managerPassword` только в текущем значении окружения Postman; оно совпадает с `CLOTHES_MANAGER_PASSWORD` запущенного API. Пароль не сохраняю в экспортируемом окружении или репозитории. Я настроил коллекцию так, чтобы она создавала уникальный логин покупателя при каждом запуске. Для поиска в Postman Lightweight API Client я также проверил `GET /api/health` и `GET /api/clothing`; оба вернули `200 OK`, снимки лежат в `docs/screenshots/`.
