# ShopSystem

Учебный интернет-магазин на .NET 8: REST API на ASP.NET Core, SQLite и настольный WPF-клиент. Клиент работает с API по адресу `http://127.0.0.1:5077`.

## Требования

- Windows;
- .NET 8 SDK или новее.

## Запуск приложения

Откройте два окна PowerShell из корневой папки `ShopSystem`.

В первом окне запустите API:

```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

Дождитесь сообщения о запуске веб-сервера. При первом запуске API создаёт SQLite-базу и демонстрационный каталог.

Во втором окне запустите настольный клиент:

```powershell
dotnet run --project .\src\ShopSystem.Desktop
```

Клиент позволяет просматривать каталог, искать товары и фильтровать их, регистрировать пользователя и входить в учётную запись, добавлять товары в корзину, менять количество и удалять позиции, покупать товар отдельно, оформлять доставку или самовывоз и просматривать историю заказов с сортировкой и деталями. Для администратора доступна панель управления товарами, категориями, пунктами выдачи и статусами заказов.

Адресная доставка разрешена только при сумме заказа больше 600 ₽. Для меньшей суммы можно оформить самовывоз из ПВЗ. Административные операции защищены ролью Admin и доступны через панель WPF после входа администратора. Учётную запись администратора можно создать при первом запуске API, передав пароль через переменную окружения `SHOP_ADMIN_PASSWORD`. Не используйте реальный пароль в учебной демонстрации.

## Сборка и тесты

Из корневой папки решения:

```powershell
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```

Ручные проверки API и пользовательских сценариев описаны в [docs/verification.md](docs/verification.md). Архитектура и исходные требования приведены в `docs/architecture.md` и `docs/assignment-pr4.md`.
