# Практическая работа №4 — интернет-магазин

Я подготовил учебный интернет-магазин на .NET 8: REST API на ASP.NET Core, SQLite и настольный WPF-клиент. Я настроил взаимодействие клиента с API по адресу `http://127.0.0.1:5077`.

## Требования

- Windows;
- .NET 8 SDK или новее.

## Запуск приложения

Для запуска я открываю два окна PowerShell из корневой папки `ShopSystem`.

В первом окне я запускаю API:

```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

Я настроил создание SQLite-базы и демонстрационного каталога при первом запуске API.

Во втором окне я запускаю настольный клиент:

```powershell
dotnet run --project .\src\ShopSystem.Desktop
```

В WPF-клиенте я реализовал просмотр каталога, поиск и фильтрацию товаров, регистрацию и вход, корзину с изменением количества и удалением позиций, отдельную покупку товара, оформление доставки или самовывоза, а также историю заказов с сортировкой и деталями. Я настроил адресную доставку для заказов от 600 ₽; при меньшей сумме я предусмотрел самовывоз из ПВЗ.

Я добавил покупателю возможность добавлять товары в избранное, удалять их оттуда и переносить в корзину. Я реализовал публикацию и изменение оценки и отзыва, вычисление среднего рейтинга и просмотр отзывов всеми посетителями. Для администратора я добавил управление товарами, категориями, ПВЗ и статусами заказов, а также удаление отзывов, нарушающих правила.

Я защитил административные операции ролью Admin. При первом запуске API я создаю учётную запись администратора, передавая пароль через переменную окружения `SHOP_ADMIN_PASSWORD`. Реальный пароль я не включал в исходники и архив.

Для проверки решения я выполняю из корневой папки команды:

```powershell

dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```
