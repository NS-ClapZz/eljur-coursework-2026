# ShopSystem

Я подготовил учебный интернет-магазин на .NET 8: REST API на ASP.NET Core, SQLite и настольный WPF-клиент. Клиент обращается к API по адресу `http://127.0.0.1:5077`.

## Требования

- Windows;
- .NET 8 SDK или новее.

## Запуск приложения

Откройте два окна PowerShell из корневой папки `ShopSystem`.

В первом окне запустите API:

```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

Дождитесь сообщения о запуске веб-сервера. При первом запуске API создаёт SQLite-базу и демонстрационный каталог.

Во втором окне запустите настольный клиент:

```powershell
dotnet run --project .\src\ShopSystem.Desktop
```

В клиенте я реализовал просмотр каталога, поиск и фильтрацию товаров, регистрацию и вход, корзину с изменением количества и удалением позиций, отдельную покупку товара, оформление доставки или самовывоза, а также историю заказов с сортировкой и деталями. Адресная доставка доступна для заказов от 600 ₽; для меньшей суммы можно выбрать самовывоз из ПВЗ.

Покупатель может добавлять товары в избранное, удалять их оттуда и переносить в корзину. Авторизованный пользователь может оставить оценку и текстовый отзыв о товаре, а затем изменить свой отзыв. Средний рейтинг вычисляется по опубликованным отзывам. Все посетители могут читать отзывы. Администратор управляет товарами, категориями, ПВЗ и статусами заказов, а также удаляет отзывы, нарушающие правила.

Административные операции защищены ролью Admin. При первом запуске API можно создать учётную запись администратора, передав пароль через переменную окружения `SHOP_ADMIN_PASSWORD`. Реальный пароль в исходники и архив не включён.

## Сборка и проверка

Из корневой папки решения выполните:

```powershell
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```

Результаты сборки, автоматических тестов и HTTP-проверок описаны в [docs/verification.md](docs/verification.md). Архитектуру и исходные требования я вынес в `docs/architecture.md` и `docs/assignment-pr4.md`.
