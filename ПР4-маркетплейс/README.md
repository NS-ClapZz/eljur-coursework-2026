# ShopSystem

Я подготовил учебный интернет-магазин на .NET 8: REST API на ASP.NET Core, SQLite и настольный WPF-клиент. Клиент обращается к API по адресу `http://127.0.0.1:5077`.

## Требования

- Windows;
- .NET 8 SDK или новее.

## Запуск приложения

Откройте два окна PowerShell из корневой папки `ShopSystem`.

В первом окне запустите API:

```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

Дождитесь сообщения о запуске веб-сервера. При первом запуске API создаёт SQLite-базу и демонстрационный каталог.

Во втором окне запустите настольный клиент:

```powershell
dotnet run --project .\src\ShopSystem.Desktop
```

В клиенте я реализовал просмотр каталога, поиск и фильтрацию товаров, регистрацию и вход, корзину с изменением количества и удалением позиций, отдельную покупку товара, оформление доставки или самовывоза, а также историю заказов с сортировкой и деталями. Для администратора я добавил панель управления товарами, категориями, пунктами выдачи и статусами заказов.

Я настроил адресную доставку только для заказа дороже 600 ₽. Для меньшей суммы доступен самовывоз из ПВЗ. Административные операции защищены ролью Admin и доступны через панель WPF после входа администратора. При первом запуске API можно создать учётную запись администратора, передав пароль через переменную окружения `SHOP_ADMIN_PASSWORD`. Для учебной демонстрации я не использую реальный пароль.

## Сборка и тесты

Из корневой папки решения выполните:

```powershell
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```

Я описал ручные проверки API и пользовательских сценариев в [docs/verification.md](docs/verification.md). Архитектуру и исходные требования я вынес в `docs/architecture.md` и `docs/assignment-pr4.md`.
