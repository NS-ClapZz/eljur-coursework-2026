# Снимки демонстрации ПР №4

Шесть кадров сделаны непосредственно из запущенного WPF-клиента во время проверки на временной SQLite-базе. Для демонстрации созданы временные аккаунты покупателя и администратора; пароли в файлы не включены. В тестовой базе остались демонстрационные избранное и отзыв, они не относятся к пользовательским данным.

- `pr4-01-catalog.jpeg` — гостевой каталог;
- `pr4-02-authenticated.jpeg` — вошедший покупатель;
- `pr4-03-favorites.jpeg` — список избранного;
- `pr4-04-review-created.jpeg` — рейтинг после публикации отзыва;
- `pr4-05-reviews.jpeg` — окно отзывов с оценкой и текстом;
- `pr4-06-admin-reviews.jpeg` — административная модерация.
