# Снимки демонстрации практической работы №4

Я сделал шесть снимков непосредственно из запущенного WPF-клиента при проверке на временной SQLite-базе. Для демонстрации я создал временные учётные записи покупателя и администратора; пароли в файлы не включал. В тестовой базе я оставил демонстрационные избранное и отзыв; пользовательские данные в ней не использовались.

- `pr4-01-catalog.jpeg` — я показал каталог для гостя;
- `pr4-02-authenticated.jpeg` — я показал приложение после входа покупателя;
- `pr4-03-favorites.jpeg` — я показал список избранного;
- `pr4-04-review-created.jpeg` — я показал рейтинг после публикации отзыва;
- `pr4-05-reviews.jpeg` — я показал окно отзывов с оценкой и текстом;
- `pr4-06-admin-reviews.jpeg` — я показал административную модерацию.
